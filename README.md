# Photo-z estimate

This project implements several Machine Learning techniques, to predict *photometric redshift (photo-z)* .

Redshift is a foundamental measure in astrophisics, because it represents the speed of recession velocity of galaxies. This information
is necessary to calculate distance and age of galaxies.

Unfortunately, obtaining redshift throught direct spectral observations is costly in terms of time of observations, and works only 
for single objects.

This problems lead the way to photometric estimate of redshift. Here redshift is called *photo-z*, and is obtained from various photometric measurements using 
ML tecniques.

This project in particular implements and compares various ML models make this prediction.

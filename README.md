# Photo-z Estimation

This project implements and compares several Machine Learning techniques for the prediction of photometric redshift (photo-z).

Redshift is a fundamental quantity in astrophysics, as it is directly related to the recession velocity of galaxies. This information is essential for estimating both the distance and the age of galaxies.

However, obtaining redshift through direct spectroscopic observations is computationally and observationally expensive, requiring significant telescope time and being feasible only for individual objects.

These limitations motivated the development of photometric redshift estimation techniques. In this context, the estimated redshift is referred to as photo-z and is inferred from photometric measurements using Machine Learning methods.

This project specifically focuses on the implementation and comparison of the following models:

* Simple baseline
* Linear Regression
* Decision Trees
* Explainable Boosting Machines (EBMs)
* Gaussian Processes for heteroscedastic data

Particular attention is devoted to model interpretability and explainability, as well as to the issue of covariate shift (CS), which commonly affects datasets used for photo-z estimation.

Finally, the performance of the analyzed models is compared with the approach proposed in the StructLearn-z article.

## Data

Four datasets are used in this study, each characterized by a different degree of covariate shift.

The datasets are labeled as follows:

* `noCS` — absence of covariate shift
* `weakCS` — low degree of covariate shift
* `mildCS` — moderate degree of covariate shift
* `strongCS` — high degree of covariate shift

Each model is evaluated on all datasets in order to analyze the degradation in predictive performance as the degree of covariate shift increases.

The datasets are provided by the StructLearn-z repository.
